# 地区地图标注复核 Implementation Plan

**Goal:** 继续已获授权的小区域地图细化，覆盖八方旅人两作全部 17 个地区，解决密集标签遮挡、出口目的地不明确与匿名路段难以对应的问题。

**Architecture:** 保留攻略相对位置及进度 ID。沿用道路编号与目录，将编号默认应用到城镇、迷宫；共用纯函数处理中文短标签换行、边界与图标避让，完整名称保留在目录和详情。出口目的地直接读取既有 to 引用。无来源不生成实际逐步走法。

**Tech Stack:** 原生 JavaScript / SVG / CSS，Node 内置测试与现有构建。

- [x] 记录两作全部地图的标注问题；给出口命名、短标签布局、道路检索补回归测试并观察失败。
- [x] 修复两作共享的名称与布局逻辑，筛选继续作用于图点及其标签，点选与进度沿用原 ID；本轮未实测浏览器交互。
- [x] 根据缓存攻略复核高密度代表地图的道路与入口，修正有依据的具体问题；保存核对范围。
- [x] 运行全部相关测试、两作校验与离线构建；检查生成入口同步、差异和标注覆盖统计。
- [x] 更新覆盖文档，明确实际核对范围和本轮未完成的实机校准。

结果：17地区329图、4047个要点、3471条道路完成名称与编号模式静态布局检查；216处出口补目的地，1118条路段补图上参照名称，0重叠/图标遮挡/越界。西克拉克里奇荒道完成11段路线与6箱入口核对，累计8图71段有逐步攻略。31项Node及4项Python测试通过，两作构建0错误0警告。独立审查发现头巾隐藏段类型遗漏，已拆成普通引路与隐藏路，补失败回归测试后修复并通过复审。

浏览器限制：现有 file:// 页面被安全策略拒绝访问，本轮不绕过该限制；浏览器交互复验不计入已通过项目。

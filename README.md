## 当前攻略可以做什么

### 八方旅人 1、2

两作分别维护世界地图、地区攻略和地点细节示意图。

- **浏览世界与地区地图**：点击地区进入，使用滚轮或按钮缩放，拖拽平移，并通过图例切换城镇、迷宫、祭坛、港口等地点的显示。
- **查看地点详情**：查阅地点介绍、宝箱、NPC 道具、商店和 Boss 攻略，结合细节示意图寻找道路、设施与出口。
- **查找任务与装备**：跨地区搜索地点、支线、道具、Boss、职业等条目，也可以在地区内进一步筛选。
- **查询隐藏地点的进入方式**：查看隐蔽入口、水路、航线、剧情条件等说明；地图上以角标和路线辅助辨认。
- **浏览小区域资料**：按道路、设施、NPC、宝箱、出口和怪物等分类查找；二代还提供资料的白天／夜晚筛选。
- **按路段查看走法**：野外地图支持道路编号与文字切换，点击路段查看相接道路；已补充逐步攻略的路段还会显示起终点、分步说明、通行提醒和来源。筛选时保留存档点、路牌、出口与岔路参照。
- **阅读全局攻略**：查看角色、职业、终章／EX、推荐路线与技巧；二代另有交汇篇资料。
- **记录完成进度**：勾选已完成条目，查看地区完成百分比。记录保存在当前浏览器本地，无需登录。

道路导航更新覆盖两作 105 张野外地图，其中 7 张地图的 60 条路段补充了分步走法。其余路段仍以现有示意路网辅助导航，尚未全部逐段复核。详情见[小区域地图覆盖与来源说明](docs/小区域地图覆盖与来源说明.md)。

### 勇者斗恶龙 I、II HD-2D 重制版

两份攻略对应 **2025 年 Nintendo Switch《勇者斗恶龙 I & II HD-2D Remake》**，分别提供流程、地图和完成记录。与 2019 年 Switch 移植版的地图和剧情有区别。

- **查看实际地图与楼层**：使用来源地图浏览道路、阶梯和设施，支持楼层切换、缩放、拖动、复位与展开。
- **查找收集物位置**：收集条目关联对应地图与拾取位置截图；地图默认叠加可对应的中文标签，也可切回日文原图，或查看“本图中文对照”。
- **检索流程与资料**：查找地点、NPC、商店商品、区域怪物、Boss、主线流程和专题，支持中文工作译名与日文原名。
- **分别记录进度**：两作使用独立的本地完成记录；世界探索点的勾选表示已探访，不代表该处物品已全部收齐。
- **查阅版本专属内容**：I 收录扎莱事件、五纹章、钥匙回访、和平巡游和终盘演出条件；II 收录四人队伍、海底探索、七处世界回忆、神龙、无限回廊与真结局路线。I 没有追加通关后迷宫。

中文名称未确认官方译名时采用工作暂译，未识别的地图注记与游戏对话保留日文。野外怪物按来源出现场所列示；来源有分歧的价格和路线在条目中说明。详见[一代说明](勇者斗恶龙1/README.md)、[二代说明](勇者斗恶龙2/README.md)和[验收记录](docs/verification/dragon-quest-hd2d.md)。

## 使用方法

### 1. 下载攻略

不使用 Git 时，点击仓库页面的 **Code → Download ZIP**，或直接[下载 ZIP](https://github.com/liqi1222/switch/archive/refs/heads/main.zip)，然后完整解压。

使用 Git 时：

```bash
git clone https://github.com/liqi1222/switch.git
cd switch
```

仓库包含地图原图、参考图片和处理资料，完整下载体积较大。请等待下载完成后再打开页面。

### 2. 打开页面

两种入口都可以直接用浏览器打开：

| 游戏 | 常规入口 | 单文件离线入口 |
| --- | --- | --- |
| 八方旅人 1 | `八方旅人1/index.html` | `八方旅人1/歧路旅人1-地图攻略.html` |
| 八方旅人 2 | `八方旅人2/index.html` | `八方旅人2/歧路旅人2-地图攻略.html` |
| 勇者斗恶龙 I | `勇者斗恶龙1/index.html` | `勇者斗恶龙1/勇者斗恶龙1-HD2D-地图攻略.html` |
| 勇者斗恶龙 II | `勇者斗恶龙2/index.html` | `勇者斗恶龙2/勇者斗恶龙2-HD2D-地图攻略.html` |

八方旅人的常规入口需要同目录的 `assets/` 和 `data/`；勇者斗恶龙的常规入口还需保留 `reference/` 中的地图和位置图片。完整下载并解压仓库即可保留这些依赖。

单文件入口已内嵌页面所需的样式、脚本与运行时图片，可单独携带。勇者斗恶龙单文件版压缩了拾取位置截图以减小体积，总览地图保持原始尺寸；常规入口保留原始位置图。

**阅读攻略不需要安装 Node.js 或 Python，也不需要启动后端服务。** 建议使用较新的 Chrome、Edge 或 Firefox。

### 3. 查找内容

八方旅人可以按地区、地点逐级浏览；勇者斗恶龙可以从世界地图、地区目录、流程章节或专题进入。以下步骤以八方旅人为例，两套攻略均支持搜索和本地完成记录。

1. 点击世界地图上的地区，查看该地区的概览、地点、主线、支线和道具。
2. 点击具体地点，查看宝箱、NPC、Boss、进入条件和细节示意图。
3. 使用顶部搜索框快速定位内容；按 `/` 可聚焦搜索，使用方向键选择结果，按 `Enter` 打开。
4. 使用 `Esc` 关闭搜索结果或逐级返回，点击“世界地图”回到总览。
5. 通过条目旁的复选框记录完成情况。

### 本地进度说明

完成记录使用浏览器的 `localStorage` 保存，**不会上传至 GitHub，也不会自动跨设备同步**。更换浏览器、清理站点数据或改变访问地址后，可能无法读取原来的记录；隐私模式下也可能无法持久保存。

## 维护与构建

这一节供修改攻略内容时使用。构建脚本使用 Node.js 内置模块，无需执行 `npm install`。

### 校验数据

在仓库根目录运行：

```bash
node "八方旅人1/build.js" --check
node "八方旅人2/build.js" --check
node "勇者斗恶龙1/build.js" --check
node "勇者斗恶龙2/build.js" --check
```

八方旅人脚本检查地区数据、地点引用、道路连接、细节图坐标与索引，以及特殊地点进入方式。勇者斗恶龙脚本检查数据引用、图片依赖、离线截图缓存和中文标注。检查通过只表示满足脚本规则，攻略内容仍需结合游戏实际情况核对。

查看完整的细节地图警告时，可增加 `--detail-verbose`：

```bash
node "八方旅人1/build.js" --check --detail-verbose
```

### 重新生成单文件攻略

修改 `data/`、`assets/` 或 `index.html` 后，运行对应游戏的构建命令：

```bash
node "八方旅人1/build.js"
node "八方旅人2/build.js"
node "勇者斗恶龙1/build.js"
node "勇者斗恶龙2/build.js"
```

构建会先校验数据，再把页面依赖内嵌到上表所列的单文件离线入口。八方旅人脚本在出现校验错误时仍会生成预览文件；勇者斗恶龙脚本遇到错误会停止，不输出新的单文件。发布前应检查输出并处理错误。

建议修改源文件后重新构建，避免只修改单文件攻略，导致下次生成时被覆盖。

勇者斗恶龙构建会内嵌全部实际引用的地图和位置图，运行时无需连接原攻略站。资料整理脚本 `勇者斗恶龙1/reference/assemble.py --game all` 负责两作数据生成，维护时使用 Python 与 Pillow，下载未缓存的新图片需要联网；普通阅读不需要这些工具。

重新整理勇者斗恶龙数据后，先从仓库根目录执行 `python 勇者斗恶龙1/reference/prepare_portable.py` 更新离线截图副本，再执行对应构建命令。调整中文地图标注时，按各作 README 中的译名表和标注脚本说明处理。

### 自动测试

勇者斗恶龙的 Node.js 测试覆盖模型、搜索、来源内容保留、楼层关联、中文标注与离线资产校验：

```bash
node --test "勇者斗恶龙1/tests/*.test.js" "勇者斗恶龙2/tests/*.test.js"
```

中文地图标注处理的 Python 测试：

```bash
python "勇者斗恶龙1/tests/test_map_annotation.py"
```

### 新增游戏目录

当前根目录的 `.gitignore` 使用白名单，已允许四个游戏文件夹和文档目录。新增游戏目录时，需要同步添加允许规则，例如新文件夹名为 `游戏名称` 时：

```gitignore
!/游戏名称/
```

随后更新游戏列表，并使用 `git status` 确认新文件已被纳入管理。

## 查阅提示与问题反馈

- 攻略包含主线、Boss、隐藏职业及终章等内容，查阅时可能遇到剧透。
- 细节地图用于辅助辨认相对位置；部分 NPC 尚未核实具体坐标。随机遇敌按区域展示，不能据此认定为固定刷新点。
- 发现名称、位置、奖励或触发条件有误时，可在 [Issues](https://github.com/liqi1222/switch/issues) 中提供游戏名称、地区／地点、问题描述和参考依据。

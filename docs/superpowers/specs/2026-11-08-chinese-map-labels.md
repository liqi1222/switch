# 地图中文标注补充

用户指出地图原图多为日文，要求提供中文或增加中文标注。本次在两作现有攻略中加入默认开启的中文文字层，可切换日文原图，不改动地图像素、道路、楼梯、指示线或世界坐标。

物品、楼层、设施、出口及地名以原有来源事实和工作暂译词典对应。来源图文字框由日文OCR定位，只在标签可对应时覆盖中文；金额不能用模糊匹配纠正，短标签或歧义保留原文，不推断新宝箱坐标。图内物品标注可关联已有拾取清单，另保留本图中文对照表。

野外世界参照图使用已有核实的城镇坐标显示中文地名。位置图在图内叠加中文说明，提供原图切换。未逐句翻译的游戏对白及未核实注记不声称已汉化。

译名属于工作暂译，日文原名、来源和独立进度ID保留。常规入口与单文件同时更新，标注数据离线内嵌。

验收：匹配歧义/数字与边界测试；标注数据坐标和源图哈希校验；浏览器查看一代洛特洞窟、二代代表地图及用户当前野外参照图，切换标注不重置缩放；位置图中文说明、手机布局及单文件内嵌资源检查。现有收集记录不迁移或重置。

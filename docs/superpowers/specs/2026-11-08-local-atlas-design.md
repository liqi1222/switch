# 两作小区域攻略地图细化

用户已确认先采用攻略资料改进两作地图，截图与探索录像后续另行处理。

现状：一代153处、二代176处地点均已有细节路网，渲染器相同。沿用既有道路、建筑、宝箱及NPC相对坐标，避免根据文字臆造实际地形。

本次交付：每张地点地图增加可检索的道路与要点目录、分类筛选、建筑/街区/楼层局部放大、从目录定位并高亮道路或图标、详情与宝箱收集状态联动。既有出口跨区跳转保持有效。商店点击显示地点已有商品推荐；NPC显示地图指令、物品及出现条件。

新增独立遇敌数据，按地点记录怪物名称、弱点及攻略明确写出的昼夜/水陆条件；有可靠资料的地点列出来源，没有资料的地点明确显示尚未核实，不表示没有敌人。随机遇敌以整个区域或水陆路段表示，绝不生成固定刷怪坐标。二代支持昼夜资料筛选，不能误删混合时间或剧情条件未知的NPC。

资料从明确对应一代或二代的攻略页面提取，保留每条来源链接与核对日期。名称无法确认官方简中译名时保留英文原名并明确提示，不杜撰中文译名。尽量交叉核对两独立攻略，单源条目标注来源状态。

离线使用及两份单文件HTML继续可用。新代码无需第三方运行依赖。验证覆盖地图目录、筛选、局部缩放、跨作资料隔离、来源、引用完整性、构建及真实浏览器交互；检查桌面与窄屏布局。

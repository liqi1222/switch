# 勇者斗恶龙 I HD-2D 重制版攻略

适用 Nintendo Switch，2025 年 HD-2D 重制版。卡带盒标有「I & II HD-2D Remake」；两部游戏分别游玩，本目录只含第 I 部。

打开 [index.html](index.html) 查阅；单独携带时打开 `勇者斗恶龙1-HD2D-地图攻略.html`。常规入口需完整保留 assets、data、reference。阅读无需安装程序。

- 从世界地图、地区目录进入地点，地图可缩放、拖动、复位、展开和切换楼层。
- 地图默认叠加可对应的中文物品、楼层、设施及出口标签，上方“中文标注”按钮可切回日文原图，切换保留缩放视野。“本图中文对照”可查中日名称；地图保留来源的实际道路、阶梯和设施；收集物可切换对应图并打开实际位置截图。
- 搜索覆盖地点、NPC、商店商品、怪物、Boss、流程和专题；中文工作译名与日文原名均可查询。按 `/` 聚焦搜索、方向键选择、Enter 打开、Esc 返回。
- 每作进度独立，勾选存于当前浏览器 localStorage；不跨设备同步。清理浏览器或改变地址可能使记录不可见。

I 收录完整主线、扎莱事件、五纹章、钥匙回访和终盘演出条件；没有追加通关后迷宫，通关后行为已单列说明。

现有 46 个地点及遇敌区域、312 条地点收集、115 条流程步骤及 63 个世界探索点。世界点的勾选代表已探访，不等于该处所有物品已收齐。地图图片统计按路径去重，世界图的多区域参照不重复算新地图。

来源与核对日期在页面「资料与来源」和具体条目中保留。[逐地点覆盖表](reference/coverage.md) 从最终数据生成；[图片核验记录](reference/verification.json) 记录所有运行时图片的解码结果。[研究说明](reference/dq1-research-report.md)列出原始事实、交叉核对和限制。

中文名称未确认官方简中时为工作暂译，原文同时显示。地图中文层为工作暂译；未识别的注记仍保留日文，位置截图增加当前条目的中文说明，未翻译全部游戏对话；未核实的 NPC 坐标、道路遇敌边界和概率不编造，普通村民对话没有穷尽。商价与路线有冲突时就地注明。资料经过来源核对与程序/浏览器验收，未声称每件物品都经过游戏实机重走。

维护命令（仓库根目录）：

```powershell
node "勇者斗恶龙1/build.js" --check
node --test "勇者斗恶龙1/tests/*.test.js"
node "勇者斗恶龙1/build.js"
```

构建会把全部引用地图、位置图、样式和脚本内嵌为单文件，出错时停止。数据来源整理统一使用 `python 勇者斗恶龙1/reference/assemble.py --game 1`；图片解码及覆盖表使用 `python 勇者斗恶龙1/reference/audit.py`。整理需要 Python/Pillow；下载新来源图片需要网络。

单文件版采用压缩的位置截图（最长边768像素），总览地图保留原始分辨率；常规入口使用原始位置图。重新整理数据后，构建前运行 `python 勇者斗恶龙1/reference/prepare_portable.py` 更新截图副本；构建会校验原图与副本哈希，拒绝过期缓存。

中文标注维护：两作共用 `勇者斗恶龙1/reference/chinese-map-terms.json` 译名表，运行 `python 勇者斗恶龙1/reference/annotate_maps.py --game all` 重建标注。OCR只用于原图文字框，不推算宝物坐标；构建验证文字框边界、来源图片哈希和收集物关联。普通阅读不需要OCR依赖或联网。

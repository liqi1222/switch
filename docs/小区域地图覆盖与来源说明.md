# 小区域地图覆盖与来源说明

更新日期：2026-11-08。按用户确认，本轮使用攻略资料改进；Switch截图、探索录像和像素级地形校准留待后续。

## 本轮交付

两作共329处地点（一代153、二代176）接入小区域目录，可搜索道路、设施、NPC、宝箱、出口和怪物。支持点选定位、道路高亮、街区/建筑/楼层放大和展开地图。商店显示已有地点商品建议，不代表该店完整库存。NPC显示已有物品、地图指令与备注；只有已关联地图标记者能定位，其他人明确标为“未定位”。二代提供资料昼夜筛选，未知及昼夜共用标记保留。

全局搜索也加入NPC与怪物名称。宝箱进度与图标同步，出口跳转保持可用。窄屏采用上下排列并可滚动目录。

本轮沿用已有示意路网，并补充卡纳尔布莱恩酒馆西侧户外桌及连接支路、昼夜两位“等待的青年”任务NPC。相对位置不等于游戏精确测量坐标；未将所有城镇重新绘制为实景平面图。

条目按区域计数，同种怪物在多个区域出现会重复计数。未覆盖区域不能理解为没有怪物。多数条目仍只有一个攻略来源，待后续复核。不同攻略或同一攻略跨页有矛盾时，不选择其中一个弱点当定论，界面显示“来源有差异，尚待核实（可能涉及章节版本）”。原始版本和来源保存在数据中。

怪物保留英文攻略名，避免杜撰官方中文译名。昼夜、水陆仅采信攻略明确条件，“时段未限定”“水陆未限定”表示来源没有限定，不保证任意条件均出现。怪物阵容可能随章节与危险等级变化。没有为随机遇敌编造固定坐标；选中怪物仅高亮相关通行路线。未加入缺乏依据的掉落率、属性数值和刷新概率。

## 来源与可复现资料

- ArrPeeGeeZ两作地点与章节攻略：主遇敌资料，各区域和怪物详情带对应原文链接；按真实页面标题及明确地点小标题匹配，不从邻区推断。
- NightlyGamingBinge二代区域攻略：用于同作怪物弱点独立交叉核对，原文链接附在条目中。
- Game8与NightlyGamingBinge支线攻略：交叉确认卡纳尔布莱恩“等待日与夜”的NPC及酒馆户外桌位置。地图内附链接。

原始页面提取文本、抓取URL和统计保存在reference-research/。coverage.json列出已覆盖的区域ID，collected.json保留攻略原文与提取行；weakness-conflicts.json记录二代来源差异。脚本collect_encounters.py、build_encounters.py、secondary_encounters.py可重建遇敌数据。

## 野外道路导航细化（追加）

共享道路编号模式覆盖两作105张野外地图（52+53）：可点编号、切换完整文字，详情列出当前示意图中的相接路段并可跳转。未补录逐步攻略的道路有明确提示。图上连接通过现有路网识别，不声称是新增实测地形。

七张图共60条路段补充起点、终点、分步走法、必要的通行提醒和来源：一代东/北利布尔泰德海道；二代卡纳尔布莱恩大桥、西卡纳尔布莱恩海道、北康宁湾海道、南科尔德凯普雪道、东弗拉姆教堂山道。大桥与雪道明确标注桥面/桥下不相通；海道第二座小岛从第一座岛继续东行再南转；修正可确认的小岔路接点。两作其他野外路线仍保留现有攻略示意，未全部重新逐段核对。

导航参照在道路、怪物等筛选下始终保留：存档点、路牌、出口及字母岔路。字母岔路是新增的攻略参照，非游戏实体路牌。补入一代北/西希·沃尔基森道两处存档点、西希·沃尔基森道北侧路口路牌、二代东科尔德凯普雪道存档点西北路牌；后两者有缓存攻略原文支持。旧数据中六个“路标”地标也统一纳入参照显示。标记仍为相对位置，未通过游戏截图测量。

路线资料编辑脚本：reference-research/refine_field_roads.py；来源链接随路段保存。新增自动测试覆盖道路编号、说明检索、详情转义、徽标避让、分层交叉、旧路牌保留及船种不误判；22项Node测试和4项Python解析测试通过。

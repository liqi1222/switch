# 野外道路标注细化

这是已获授权的小区域地图改进的后续修正。用户指出部分野外道路标注不清，继续按既定“攻略文字核对、相对位置示意、以后再做截图校准”的方案执行。

根因：274条野外路段无名称；有名称的长文字直接沿道路排版，岔路和桥下水路容易叠字；目录不展示道路备注，路线详情缺少连续走法。

共享改进覆盖两作105张type=field地图：默认用可点击道路编号替代沿路长文字，编号与道路目录一致，保留完整文字切换。目录显示已有路线说明；详情显示通行方式、起止地标、分步走法与攻略来源。没有逐步资料的路段明确保留已有示意信息，不自动推断实际通路。

本轮优先逐段补充二代卡纳尔布莱恩大桥、西卡纳尔布莱恩海道、北康宁湾海道、南科尔德凯普雪道、东弗拉姆教堂山道，以及一代东/北利布尔泰德海道。分开步行、梯子、桥面和独木舟路线；桥下交叉明确标注上下层不连通。保留宝箱进度和出口引用。

验证：道路文字与详情来源、图标避让、编号一致性、桥面/桥下分层、所有旧测试、两作构建；浏览器检查大桥、海岸与雪道，窄屏和单文件。无git仓库，不执行提交。

用户补充要求：必须加入存档点、实体路牌与道路相对关系。已纳入设计：参照分类、筛选始终保留导航锚点、图上相接路段及可点选连接、补攻略明确的存档点和实体路牌。字母岔路与实体路牌分别显示。
